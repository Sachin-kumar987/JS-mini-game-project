🎮 JavaScript Mini Game Projects

A collection of fun and interactive JavaScript Mini Games built using HTML, CSS, and Vanilla JavaScript. This project showcases multiple classic games designed with modern UI and smooth interactivity, making them both entertaining and a great learning experience.


🚩 Live Demo

   Current version running at:  https://js-mini-gamepro.netlify.app/
   


✨ Included Games


🎴 Memory Game – Test your memory skills by matching pairs of cards.

🔨 Hammer the Mole – A reflex-based game where you score points by clicking moles.

🎯 Hangman Game – Guess the hidden word before you run out of chances.

📊 Quiz Game – Answer multiple-choice questions with instant feedback.

🐍 Snake Game – Classic snake game with score tracking.

✊✋✌ Rock Paper Scissors – Play against the computer with random choices.

⭕❌ Tic Tac Toe – A two-player or AI-based strategic board game.

♟ Chess Game – A simplified chess game to challenge your strategy.




⚙️ Technologies Used


HTML5 – For semantic structure of each game

CSS3 – For styling, layouts, animations, and responsiveness

JavaScript (Vanilla JS) – For game logic, interactivity, and DOM updates



🎯 Purpose of the Project



The goal of this project is to:

Strengthen problem-solving and logical thinking using JavaScript

Practice DOM manipulation and event-driven programming

Build a collection of mini-games that demonstrate core web development skills

Showcase UI/UX design with a clean, playful, and responsive interface

Provide fun and engaging games while also serving as portfolio projects
